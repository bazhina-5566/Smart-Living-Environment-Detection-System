三、全局变量 (可直接读取, 不建议外部写入)
--------------------------------------------------------------------------------
  变量名             类型    说明
  ─────────────────────────────────────────
  fan_gear           u8      当前风扇档位 (0~10), 核心控制变量
                             0=停止, 1~10 对应 10%~100% 占空比

  fan_rgb_state      u8      当前 RGB 状态
                             0=FAN_RGB_OFF   熄灭
                             1=FAN_RGB_GREEN 绿灯 (占空比 ≤ 50%)
                             2=FAN_RGB_BLUE  蓝灯 (占空比 51%~80%)
                             3=FAN_RGB_RED   红灯 (占空比 > 80%)

  读取示例:
    if (fan_gear >= 5) { ... }              // 判断当前档位
    if (fan_rgb_state == FAN_RGB_RED) { ... } // 判断RGB处于红灯

4.1  Fan_KeyControl() — 按键风扇调速 + RGB联动
--------------------------------------------------------------------------------
  声明:     void Fan_KeyControl(void);
  所在文件: project.c 第 51 行
  调用频率: 每个主循环周期调用一次 (约 5~10ms 间隔)
  是否阻塞: 否 (无延时/无忙等, < 几十微秒即返回)

  功能描述:
    读取 KEY2(PB0, 上拉, 低电平有效) 和 KEY3(PB1, 上拉, 低电平有效)
    单击 KEY2 → fan_gear +1 (档位增加, 最大到 10)
    单击 KEY3 → fan_gear -1 (档位减小, 最小到 0)
    档位变化时自动:
      ① 换算 speed = fan_gear * 100 → 调用 Fan_SetSpeed(speed)
      ② 根据占空比判定 fan_rgb_state
      ③ 驱动 4 颗 WS2812B 灯珠变色
      ④ 串口打印 "[FAN] gear=X  duty=XX%  speed=XXX  RGB=XXXX"

  档位对照表:
    gear  占空比   speed    RGB灯珠
    ────────────────────────────────
     0      0%       0      熄灭
     1     10%     100      绿灯
     2     20%     200      绿灯
     3     30%     300      绿灯
     4     40%     400      绿灯
     5     50%     500      绿灯
     6     60%     600      蓝灯
     7     70%     700      蓝灯
     8     80%     800      蓝灯
     9     90%     900      红灯
    10    100%     999      红灯

  硬件资源:
    输入: PB0(KEY2), PB1(KEY3) — 已在 KEY_Init() 中初始化
    输出: PC8(TIM8_CH3) PWM — 已在 Fan_Config() 中初始化
    输出: PB15(WS2812B) — 已在 Rgb_Config() 中初始化

  重要说明:
    ★ 必须在主循环中高频调用 (不能放在定时器回调或条件分支内)
    ★ 内部使用 sys_tick 做 30ms 硬件消抖
    ★ 按住不放只触发一次 (无反覆连发)
    ★ Fan_Config(), KEY_Init(), Rgb_Config() 必须在调用此函数前已初始化

  ┌─ 正确用法 ─────────────────────────────────────┐
  │ while(1) {                                     │
  │     Fan_KeyControl();  // 每次循环都调用        │
  │     // ... 其他逻辑 ...                         │
  │ }                                               │
  └─────────────────────────────────────────────────┘

  ┌─ 错误用法 ─────────────────────────────────────┐
  │ if (sht30_flag == 1) {                         │
  │     Fan_KeyControl();  // 错! 只在条件内调用    │
  │ }                    // 按键响应将严重延迟      │
  └─────────────────────────────────────────────────┘


4.2  Fan_DisplayStatus() — LCD 风扇进度条 + 串口输出
--------------------------------------------------------------------------------
  声明:     void Fan_DisplayStatus(void);
  所在文件: project.c 第 174 行
  调用时机: 需要刷新 LCD 风扇显示时调用
  是否阻塞: 是 (约 50~100ms, 包含 LCD SPI 传输和 W25Q64 字库读取)

  功能描述:
    读取 fan_gear 和 fan_rgb_state, 在 LCD 上绘制:
      ① 标题: "风扇转速: XX%" (y=180)
      ② 进度条: 200x18px 水平柱状 (y=203), 边框黑色, 填充色=RGB状态色
      ③ 状态: "RGB: 熄灭/绿灯/蓝灯/红灯" (y=228)
    同时串口输出: "[LCD] 风扇:XX%  RGB:XXXX"

  LCD 显示区域:
    ┌──────────────────────────┐ y=178 清除区
    │  风扇转速: 60%           │ y=180
    │  ████████████░░░░░░░░░░  │ y=203 进度条
    │  RGB: 蓝灯               │ y=228
    └──────────────────────────┘ y=248

  注意:
    ★ 此函数会清除 y=178~248 区域
    ★ 与 Sensor_Display_All() 的显示区域 (y=65~150) 不重叠, 可同时显示
    ★ 内部通过 Lcd_ZikuStr → W25Q64 读取字库, 依赖 W25Q64_Config() 已初始化


4.3  Sensor_Display_All() — 火焰+光敏传感器显示
--------------------------------------------------------------------------------
  声明:     void Sensor_Display_All(void);
  所在文件: project.c 第 270 行
  调用时机: 需要刷新传感器数据时调用
  是否阻塞: 是 (约 50~100ms, 含 ADC 转换等待和 LCD/W25Q64 操作)

  功能描述:
    ① 调用 Flame_GetValue()  — 读取 PC1 火焰传感器 (ADC1_IN11)
    ② 调用 ADC1_GetValue()   — 读取 PC0 光敏电阻   (ADC1_IN10)
    ③ 串口输出:
        火焰传感器: XX.X%
        光敏电阻:   XX.X%
    ④ LCD 显示 (带名称标签):
        火焰传感器: XX.X%   (y=65 标签, y=85 数值)
        光敏电阻:   XX.X%   (y=115 标签, y=135 数值)

  LCD 显示区域:
    ┌──────────────────────────┐ y=65 清除区
    │  火焰传感器: 75.5%       │ y=65/85
    │                          │
    │  光敏电阻:   60.3%       │ y=115/135
    └──────────────────────────┘ y=150

  注意:
    ★ 此函数会清除 y=65~150 区域
    ★ 依赖 ADC1_Config() 和 Flame_Config() 已初始化
    ★ Flame_GetValue() 和 ADC1_GetValue() 内部已去除 printf,
      串口输出统一由此函数负责, 保证输出整洁不重复

五、初始化顺序 (main.c 中必须严格遵守)
--------------------------------------------------------------------------------
  正确的初始化顺序 (由上到下):

    LED_Init();            // ① LED (PD12/13/14)
    KEY_Init();            // ② 按键 (PA0/PB0/PB1)
    Buzzer_Init();         // ③ 蜂鸣器 (PD15)
    Relay_Init();          // ④ 继电器 (PE0)
    Fan_Config();          // ⑤ 风扇 PWM (PC8, TIM8_CH3)
    Servo_Init();          // ⑥ 舵机 PWM (PA1, TIM5_CH2)
    Rgb_Config();          // ⑦ RGB 灯珠 (PB15)
    Sht30_Config();        // ⑧ SHT30 温湿度 (PB6/PB7, I2C1)
    MLX90614_Config();     // ⑨ 红外测温 (PB6/PB7, I2C1)
    LCD_Init();            // ⑩ LCD 显示屏
    Usart1_Config(115200); // ⑪ 串口 (PA9/PA10)
    W25Q64_Config();       // ⑫ 外部存储 (SPI1)
    ADC1_Config();         // ⑬ ADC (PC0/PC1)
    Flame_Config();        // ⑭ 火焰传感器 GPIO (PC1)

     ⚠ Fan_Config() 必须在 Fan_KeyControl() 之前
     ⚠ RGB_Config()  必须在 Fan_KeyControl() 之前
     ⚠ LCD_Init()    必须在 Fan_DisplayStatus() / Sensor_Display_All() 之前
     ⚠ W25Q64_Config() 必须在 LCD 字库显示之前 (Lcd_ZikuStr 依赖)
     ⚠ ADC1_Config() 必须在 Sensor_Display_All() 之前

六、完整使用示例 (最小可运行代码)
--------------------------------------------------------------------------------

  #include "main.h"       // 已包含 project.h

  int main(void)
  {
      // ===== 硬件初始化 =====
      LED_Init();
      KEY_Init();
      Buzzer_Init();
      Relay_Init();
      Fan_Config();
      Servo_Init();
      Rgb_Config();
      Sht30_Config();
      MLX90614_Config();
      LCD_Init();
      Usart1_Config(115200);
      W25Q64_Config();
      ADC1_Config();
      Flame_Config();

      SysTick_Config(SystemCoreClock / 1000);  // 1ms 中断

      // ===== 首次显示 =====
      Sensor_Display_All();     // 火焰+光敏
      Fan_DisplayStatus();      // 风扇进度条

      // ===== 主循环 =====
      while (1)
      {
          Fan_KeyControl();     // ① 必须每次循环调用

          if (sht30_flag == 1)  // SysTick 每 1 秒置 1
          {
              sht30_flag = 0;
              Sensor_Display_All();   // ② 刷新传感器
              Fan_DisplayStatus();    // ③ 刷新风扇
          }
      }
  }

七、模块集成指南 (给同事)
--------------------------------------------------------------------------------

  场景 A: 只需要风扇按键调速功能
  ─────────────────────────────────
    ① #include "project.h"
    ② 确保初始化: KEY_Init(), Fan_Config(), Rgb_Config()
    ③ 主循环中调用 Fan_KeyControl()
    ④ 读取 fan_gear 和 fan_rgb_state 获取状态

  场景 B: 只需要 LCD 风扇进度条显示
  ─────────────────────────────────
    ① #include "project.h"
    ② 确保初始化: LCD_Init(), W25Q64_Config(), Fan_Config(), Rgb_Config()
    ③ 需要时调用 Fan_DisplayStatus()
    ④ 不要与 Sensor_Display_All() 同时调用 (会互相清屏覆盖)

  场景 C: 只需要火焰/光敏传感器显示
  ─────────────────────────────────
    ① #include "project.h"
    ② 确保初始化: LCD_Init(), W25Q64_Config(), ADC1_Config(), Flame_Config()
    ③ 需要时调用 Sensor_Display_All()
    ④ 读取 flame_value / light_value 获取传感器百分比值
    ⑤ 注意: Flame_GetValue() 和 ADC1_GetValue() 可独立调用
           但它们内部不再有 printf, 仅更新全局变量

  场景 D: 集成到现有页面系统 (Page_One / Page_Two)
  ─────────────────────────────────
    ① 在 Page_One() 中:
       - 放置 4 个设备控制按钮 (LED/风扇/蜂鸣器/继电器) — 原有代码
       - 加一个区域显示风扇进度条: 调用 Fan_DisplayStatus()
       - 加一个区域显示传感器值: 调用 Sensor_Display_All()

    ② Fan_KeyControl() 放在主循环 while(1) 顶层,
       不要放在 if(ui_flag==0) 条件内部

  场景 E: 需要同时显示传感器和风扇 (当前默认布局)

九、串口输出格式 (波特率 115200, 8N1)
--------------------------------------------------------------------------------
  上电时:
    OK
    初始化成功!
    ========== 风扇按键调速测试 ==========
      KEY2: 增速(+10%占空比/档)
      KEY3: 减速(-10%占空比/档)

    [FAN] gear=6  duty=60%  speed=600  RGB=BLUE

  定时刷新时 (~每1秒):

    光敏电阻:   60.3%

    ★ 用英文终端也能看到所有 ASCII 部分 (数值、标签缩写等)

十、常见问题 FAQ
--------------------------------------------------------------------------------
  Q1: 按键没反应?
  A1: 检查 ① KEY_Init() 是否已调用
           ② Fan_KeyControl() 是否在主循环中每次调用 (不能放在 if 内)
           ③ sys_tick 是否在 SysTick_Handler 中正常递增

  Q2: LCD 显示乱码或白屏?
  A2: 检查 ① LCD_Init() 是否先于 Fan_DisplayStatus() 调用
           ② W25Q64_Config() 是否已调用 (字库读取依赖)
           ③ SPI1 / W25Q64 硬件是否正常

  Q3: 风扇不转?
  A3: 检查 ① Fan_Config() 是否已调用
           ② fan_gear 是否 > 0 (可用串口查看)
           ③ PC8 引脚是否连接正确

  Q4: RGB 灯珠不亮?
  A4: 检查 ① Rgb_Config() 是否已调用
           ② PB15 引脚连接
           ③ fan_gear > 0 时 RGB 才会亮 (0 档 = 熄灭)

  Q5: 串口无输出?
  A5: 检查 ① Usart1_Config(115200) 是否已调用
           ② 串口终端波特率是否设为 115200
           ③ TX 引脚 PA9 连接

  Q6: 如何修改档位数量?
  A6: 修改 project.h 中的 FAN_GEAR_MAX 宏 (当前=10)
      同时调整 FAN_DUTY_GREEN_MAX / FAN_DUTY_BLUE_MAX 阈值

  Q7: 如何修改 LCD 显示位置?
  A7: 修改 project.c 中 Fan_DisplayStatus() 和 Sensor_Display_All()
      的 x, y 坐标参数 (Lcd_Clear, Lcd_ZikuStr 等调用处)

  Q8: 如何搭配触摸屏切换页面?
  A8: Fan_KeyControl() 放在 while(1) 最外层
      CST_Scan() 也放在 while(1) 外层
      页面切换时用 ui_flag 触发 Fan_DisplayStatus() / Sensor_Display_All()
