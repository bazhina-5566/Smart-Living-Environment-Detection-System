## 📖 项目简介

**智慧生活环境检测系统** 是一款以 **STM32F405VGT6**（ARM Cortex-M4）为核心的嵌入式智能环境监测与设备控制平台。系统集成了多种环境传感器和执行器，通过 **240×320 SPI 触摸液晶屏** 提供直观的人机交互界面，支持触摸手势滑动切换四个功能页面，实现了环境数据采集、设备智能控制、传感器状态可视化等完整的智能家居功能闭环。

### 🎯 核心亮点

- 🔄 **四页面触摸交互**：主页展示 / 设备控制 / 系统状态 / 传感器监测，左右滑动切换
- 🌡️ **多传感器融合**：温湿度 (SHT30)、红外测温 (MLX90614)、火焰检测、光敏电阻
- 🎛️ **多设备联动控制**：风扇无级调速（11 档）、舵机角度、LED 多模式、RGB 灯带氛围灯
- 🔗 **智能联动逻辑**：舵机角度自动联动风扇转速与继电器开关
- 📊 **LCD 可视化**：进度条、实时数据、彩色状态指示
- 💻 **串口指令控制**：支持 UART 指令远程操控所有设备

## ✨ 功能详情

### 🌐 四页面触摸交互系统

| 页面 | 名称 | 功能描述 | 触发方式 |
|:----:|------|----------|----------|
| **Page 0** | 🏠 **主页** | 系统 Logo 展示 + 创作者签名 | 上电默认 |
| **Page 1** | 🎮 **设备控制** | LED 开关 / 风扇开关，彩色触摸按钮 | 右滑一次 |
| **Page 2** | 📊 **系统状态** | LED/Fan 实时状态 + 风扇进度条 + RGB 指示 | 右滑两次 |
| **Page 3** | 📡 **传感器监测** | 火焰传感器 + 光敏电阻实时百分比数据 | 右滑三次 |

> 💡 任意页面右滑即切换到下一页，循环轮换。每次切换伴随蜂鸣器提示音。

### 🌡️ 环境传感器系统

| 传感器 | 型号 | 通信接口 | 测量参数 | 精度 |
|--------|------|----------|----------|------|
| 温湿度传感器 | **SHT30** | I²C (PB6/PB7) | 温度 + 相对湿度 | ±0.3°C / ±2%RH |
| 红外测温传感器 | **MLX90614** | I²C (PB6/PB7) | 非接触式物体温度 | ±0.5°C |
| 火焰传感器 | — | ADC1_IN11 (PC1) | 火焰强度百分比 | — |
| 光敏电阻 | — | ADC1_IN10 (PC0) | 环境光照百分比 | — |

### 🎛️ 执行器系统

| 设备 | 控制方式 | 参数范围 | 特性 |
|------|----------|----------|------|
| 🔴 **LED 灯组** | GPIO (PD12/13/14) | 开/关/闪烁/呼吸 | 4 种工作模式 |
| 🌀 **散热风扇** | PWM TIM8_CH3 (PC8) | 0~10 档 (0%~100%) | 11 级无级调速 |
| 💡 **RGB 灯带** | WS2812B ×4 (PB15) | 灭/绿/蓝/红 | 根据风速自动变色 |
| 🔧 **舵机** | PWM TIM5_CH2 (PA1) | 0° ~ 180° | 5° 精度控制 |
| 🔊 **蜂鸣器** | GPIO (PD15) | 开/关 | 触摸反馈提示 |
| ⚡ **继电器** | GPIO (PE0) | 开/关 | 舵机角度联动 |

### 🔗 智能联动逻辑

```
舵机角度 θ          风扇转速       继电器状态      RGB 指示
─────────────────────────────────────────────────────────
  0° ~ 45°          关闭            吸合 (ON)         —
 46° ~ 90°          关闭            释放 (OFF)        —
 91° ~ 120°         30% (3 档)      释放 (OFF)        🟢 绿灯
121° ~ 150°         60% (6 档)      释放 (OFF)        🔵 蓝灯
151° ~ 180°        100% (10 档)     释放 (OFF)        🔴 红灯
```

### 💻 串口指令系统

通过 UART1 (PA9/PA10, 256000bps) 发送指令远程控制：

| 指令 | 功能 | 示例 |
|------|------|------|
| `led on` | 打开 LED | `led on` |
| `led off` | 关闭 LED | `led off` |
| `led flash` | LED 闪烁模式 | `led flash` |
| `led breath` | LED 呼吸模式 | `led breath` |
| `servo 90` | 舵机转到 90° | `servo 90` |
| `servo +10` | 舵机角度 +10° | `servo +10` |
| `servo -10` | 舵机角度 -10° | `servo -10` |

## 🔑 关键技术细节

### 风扇 RGB 联动算法

```
档位 0:   占空比   0% → RGB 熄灭
档位 1~5: 占空比  10%~50% → RGB 绿灯 🟢 (安全区间)
档位 6~8: 占空比  60%~80% → RGB 蓝灯 🔵 (警告区间)
档位 9~10: 占空比 90%~100% → RGB 红灯 🔴 (危险区间)
```

### 触摸消抖策略

- 使用 200ms 软件消抖窗口（`TOUCH_DEBOUNCE_MS`）
- 基于 `sys_tick` 毫秒计数器实现非阻塞延时判断
- 单次触摸只触发一次动作，防止连击

### 页面渲染优化

- 采用 `ui_flag` 标志位机制：静态内容仅在页面首次进入时绘制
- 动态数据（传感器值、LED/Fan 状态）每秒刷新一次（基于 SysTick）
- 风扇按键扫描每主循环周期执行（5~10ms），保证响应及时

## ⚠️ 注意事项

1. **初始化顺序**：硬件初始化有严格的依赖顺序，详见 `project_manual.txt` 第五章
2. **串口编码**：中文输出使用 **GB2312** 编码，串口终端需对应设置
3. **字库依赖**：LCD 中文字符显示依赖 W25Q64 中的字库文件，首次使用需烧写字库
4. **PWM 冲突**：风扇 (TIM8_CH3) 与舵机 (TIM5_CH2) 使用不同定时器，互不冲突
5. **I²C 总线共享**：SHT30 和 MLX90614 共用 I²C1 (PB6/PB7)，地址不同（0x44 vs 0x5A）
